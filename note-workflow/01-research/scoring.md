# 売れ筋スコアリング・ルーブリック

noteは記事ごとの販売実数を公開しないため、公開シグナルの合成で「売れている度」を推測する。

## sellability_score（0〜1）

各要素を 0〜1 に正規化してから重み付き合計する。

| 要素 | 重み | 正規化のしかた |
|------|------|--------------|
| スキ数のジャンル内相対順位 | 0.35 | 収集した候補群の中でのパーセンタイル |
| 人気/急上昇タブ掲載 | 0.20 | 掲載=1, 非掲載=0 |
| Xでの「買った/良かった」言及数 | 0.15 | 0件=0, 1〜2=0.5, 3件以上=1 |
| 価格が衝動買い帯(300〜980円) | 0.15 | 帯内=1, 外=0.3 |
| 著者フォロワー数 | 0.10 | log10(followers)/5 を上限1でクリップ |
| 鮮度（直近30日投稿） | 0.05 | 30日内=1, 90日内=0.5, それ以外=0.2 |

```
sellability_score =
    0.35*rank_like + 0.20*tab + 0.15*x_mentions
  + 0.15*price_band + 0.10*author + 0.05*freshness
```

**なぜスキ数が使えるか**：note内では売上額は非表示だが、スキ数は売上と強く相関する
（購入者・読了者ほどスキを押す傾向）。ただしスキ買い/相互スキで水増しされた記事に注意し、
「スキは多いがXで一切言及がない」ものは x_mentions=0 で自然に減点される設計。

## durability チェック（1年後も売れるか / 4項目）

各テーマに YES/NO。**3つ以上YESで通過**。

1. **課題の普遍性**：解決している悩みは来年も存在するか？
   （例：「AIで文章に体温を出す」=YES / 「今月の新ツール速報」=NO）
2. **ツール非依存**：特定サービスの現行UIに依存していないか？
   仕様変更で陳腐化するならNO。抽象化して残せるならYESに書き換える。
3. **検索/回遊の入口があるか**：来年も検索・タブ・SNSから新規読者が来る導線があるか。
4. **体験・型の再現性**：「やってみた/失敗込み全公開」等、著者が変わっても通用する型か。
   （note公式分析でも "リアルな体験談ベース" が伸びると出ている）

## 出力に必ず添えること
- スコアは推測（実販売数ではない）である旨。
- 除外テーマとその理由（一過性判定の透明性）。
