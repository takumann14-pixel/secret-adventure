# 01 リサーチ担当

## 役割
毎朝、noteで「300円前後で売れている」有料記事を収集し、
**1年後も売れ続けるテーマだけ**を抽出してスコア付きリストにする。

## 実行手順（自動）

1. **収集**：以下を横断検索して候補記事を集める（最低30件）。
   - note内検索：対象ジャンル（AI活用/知的生産/副業）を「人気」「急上昇」タブで
   - note公式の分析記事・まとめ（note.jp のレポート）
   - X検索：`note 買った 良かった (ジャンル名)`、`{記事タイトル}` の反応
   - 各記事から取得：タイトル / URL / 価格 / 有料無料 / スキ数 / 著者フォロワー数 / 投稿日 / 主題

2. **スコアリング**：`scoring.md` の式で `sellability_score`（0〜1）を計算。

3. **耐久フィルタ**：`scoring.md` の durability チェック（YES/NO 4項目）を適用。
   3項目以上YESのテーマだけ通過 = "1年後も売れる"候補。

4. **出力**：`output/YYYY-MM-DD/01-research.md` に、通過テーマを score 降順で表化。
   各テーマに「なぜ1年後も売れるか」を1行添える。

## 出力フォーマット

```markdown
# リサーチ結果 YYYY-MM-DD

## 通過テーマ（1年後も売れる / score降順）
| score | テーマ | 代表記事の型 | 価格帯 | 耐久理由 |
|-------|--------|------------|--------|----------|
| 0.82  | ...    | ...        | 300〜500 | ...    |

## 除外（一過性トレンド）
- {テーマ} … 除外理由
```

## 注意
- 実販売数は非公開。スコアはあくまで公開シグナルの合成＝推測であると明記する。
- 特定ツール名に依存したテーマ（例:「◯◯という新アプリ完全攻略」）は耐久フィルタで落ちやすい。
  抽象度を1段上げた課題ベース（「AIで文章の"自分らしさ"を保つ」等）に言い換えて残す。
