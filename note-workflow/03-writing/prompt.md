# 03 執筆担当

## 役割
採用テーマ1本を、**4,000字前後**の300円noteに仕上げる。
無料公開部分で読者を引き込み、**有料の境界**を「ここから先が本編」の最も欲しい直前に置く。

## 入力
`output/YYYY-MM-DD/02-themes.md` の1位テーマ。

## 構成テンプレート（無料/有料の境界設計）

```
【無料パート ＝ 全体の35〜45%・約1,500〜1,800字】
1. フック（100字）……読者の「痛い現実」を一文で刺す
2. 共感と自己開示（300字）……私も同じで失敗した、の1人称
3. 結論の予告（200字）……この記事で何が手に入るかを断言
4. 全体像・目次（150字）……有料に何が入るか透けさせる
5. 無料で1つだけ本物の価値を渡す（500〜700字）
   ……出し惜しみせず「1個だけ」完全に有益なノウハウを無料で渡す（信頼の担保）
──────────── 💰 有料境界ここ ────────────
   境界の直前に「ここから先は、実際に私が◯◯した具体的手順です」と最も欲しい所で切る

【有料パート ＝ 55〜65%・約2,200〜2,500字】
6. 手順/型を具体で（見出し3〜5本、各400字）……真似できる粒度。数字・固有の失敗を入れる
7. つまずきポイントと回避（400字）
8. テンプレ or チェックリスト（買った人が即使える"お土産"）
9. 締め（200字）……行動を1つだけ指定。次記事/マガジンへ導線
```

## ルール
- **1人称**。体温のある語り。断定を恐れない。
- 無料パートで「1個だけ本物」を渡すと購入率が上がる（出し惜しみ全開は逆効果）。
- 有料の核＝「私が実際にやった具体手順・数字・失敗」。一般論はすべて無料側へ。
- 文字数は本文で4,000字±10%。見出しは具体的動詞で。
- この時点では"素の原稿"でよい（AIっぽさは04検品で除去する）。

## 出力
`output/YYYY-MM-DD/03-draft.md`。境界は `<!-- 💰 有料境界 -->` で明示。
先頭にメタ（タイトル/価格/ターゲット/想定文字数）を frontmatter で付ける。
