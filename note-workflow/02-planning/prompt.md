# 02 企画担当

## 役割
リサーチ結果（01）と過去の売れ行きデータ（`history.csv`）を照らし合わせ、
「次に書くnoteのテーマ」を**10本**提案する。

## 入力
- `output/YYYY-MM-DD/01-research.md`（当日の通過テーマ）
- `02-planning/history.csv`（自分の過去記事の実績。無ければ空でOK、初回はリサーチのみで提案）

## history.csv の形式
```csv
date,title,theme_tag,price,sold_estimate,likes,x_impressions,note
2026-08-10,ChatGPTに自分の言葉で書かせる,ai-writing,300,42,180,12000,固定ツイで伸びた
```
`sold_estimate` は自己申告の販売数（noteの売上画面から手入力）。学習の元になる。

## 手順
1. history.csv を集計 → 自分の実績が高い `theme_tag` 上位を把握（当たり筋）。
2. 01のリサーチ通過テーマと突き合わせ、
   - **勝ちパターンの横展開**（過去に売れたtagの新しい切り口）
   - **市場が伸びてて自分が未参入**の空白テーマ
   を混ぜて10本作る。
3. 各案に：タイトル案 / 想定読者の悩み / 300円で買う理由（有料の核） / 予想スコア（01基準の推測）/ 勝ち筋の根拠（history or 市場）。
4. 10本を「今日書くべき順」に並べ、**1位に採用理由**を明記。

## 出力
`output/YYYY-MM-DD/02-themes.md` に10本の表。1位が03（執筆）の入力になる。

## 出力フォーマット
```markdown
# 企画 10本 YYYY-MM-DD
| 順位 | タイトル案 | 読者の悩み | 300円で買う理由 | 予想score | 勝ち筋根拠 |
|------|-----------|-----------|----------------|-----------|-----------|
| 1 ★  | ...       | ...       | ...            | 0.8       | 過去ai-writingが平均販売40部 |

★採用理由：...
```
